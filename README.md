# 📒 دفترچه تلفن — Phone Book

نسخه آفلاین و تک‌فایل دفترچه تلفن فارسی. بدون سرور، بدون نصب — فقط فایل `index.html` را در مرورگر باز کنید.

Offline single-file Persian phone book. No server, no install — just open `index.html` in a browser.

## امکانات | Features
- ثبت، ویرایش و حذف مخاطب (add / edit / delete contacts)
- جست‌وجو، فیلتر گروه، علاقه‌مندی‌ها (search, group filter, favorites)
- ورود از CSV و Excel، خروجی CSV، بکاپ/بازگردانی JSON (CSV/Excel import, CSV export, JSON backup & restore)
- یادآور تولدهای ۳۰ روز آینده (upcoming birthdays)
- ذخیره‌سازی در خود مرورگر (localStorage) — داده‌ها روی دستگاه شما می‌مانند
